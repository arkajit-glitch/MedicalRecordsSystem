This project is a decentralized **Medical Records Management System** built using **Soroban Smart Contracts** on the Stellar blockchain.

The goal is to securely store and manage patient medical data in a **tamper-proof, transparent, and decentralized manner**, ensuring privacy and data integrity.

---

## ⚙️ What It Does

This smart contract allows patients to:

* Store their medical records on-chain
* Retrieve their medical information anytime
* Update their records securely
* Delete records when needed

Each record is associated with a unique Stellar address, ensuring **ownership and authentication**.

---

## ✨ Features

* 🔐 **Secure Access Control**
  Only the patient (wallet owner) can create, update, or delete their records.

* 📦 **On-Chain Storage**
  Medical data is stored directly on the blockchain for transparency and immutability.

* 🔄 **CRUD Operations**

  * Create records
  * Read records
  * Update records
  * Delete records

* 🧾 **Structured Data Storage**
  Each record includes:

  * Name
  * Age
  * Diagnosis
  * Treatment

* ⚡ **Decentralized & Trustless**
  No central authority controls the data.

## 📦 Smart Contract Functions

| Function        | Description                       |
| --------------- | --------------------------------- |
| `set_record`    | Create or update a medical record |
| `get_record`    | Retrieve a patient's record       |
| `delete_record` | Remove a medical record           |
